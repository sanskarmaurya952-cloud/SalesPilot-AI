# 🚀 SalesPilot AI

### The AI Sales Agent that doesn't just talk — it understands, adapts and acts.

SalesPilot AI is a **context-aware adaptive AI sales agent** built with **Agora Conversational AI**.

Unlike a generic AI calling bot, SalesPilot continuously understands the customer's:

- 🎯 Intent
- 😊 Sentiment
- 🚧 Objections
- 🛒 Buying stage
- 💰 Budget
- 👤 Customer profile
- 🧠 Previous conversation context

It then dynamically changes its sales strategy and recommends the **next best action**.
